5.2.2 Calculating the fraction of the population occupied by the dominant taxon from one sample

Lets say you’ve pulled 6 LEGO bricks out of your bag, and we’re interested in a taxon of Blue bricks. Maybe we already know this is likely the dominant taxon based on other existing literature or observations made in this area.

# The number of bricks you pulled out of your back gives you the sample size
sample_size <- 6 

#The number of those bricks that are from the dominant taxon
sample_number_dominant_individuals <- 1 

# The fraction or proportion of the sample that is the dominant taxon
sample_dominant_fraction <- sample_number_dominant_individuals/sample_size

#display the value 
print(sample_dominant_fraction)
[1] 0.1666667

5.2.3 Calculating the fraction of the population occupied by the dominant taxon from multiple samples

We need to know how many samples we’ve taken later on, but we also need to sum the total number of individuals per sample. The code below drops the first row (‘Sample’), but sums the number of individuals

# Create a community data object selecting only the lego colours
# Note that we are overwriting the original community_data object with this new mutated version
community_data <- community_data |>
  mutate("Total" = rowSums(community_data[,-1]))

Assuming we are interested in the blue lego species, we can calculate the cumulative sum of the sample size, and the number of blue individuals from samples 1, 1+2, 1+2+3, … etc. We can then find the relative proportion of the number of blue individuals to the total number of all individuals.

cumulative_total <- cumsum(community_data$Total)
cumulative_blue <- cumsum(community_data$blue)
proportion_blue <- cumulative_blue/cumulative_total

Next, we need to plot the fraction of blue to total individuals against sample size.

Notice that in this ggplot code, we’re not specifying data = community_data; this is because we’re using the object proportion_blue that we created above on our y axis, which is not contained in the dataset.

We can still call the sample column from community_data using the $ notation.

ggplot() +
  geom_point(aes(x = community_data$sample, y = proportion_blue)) + 
  scale_x_discrete(name = "Cumulative number of samples") + 
  scale_y_continuous(name = "Proportion blue",
                   expand = c(0,0),
                   limits = c(0.5,0.7)) + 
  theme_bw()

5.2.4 Applying the Poisson distribution test to our lego data

We’re still interested in the distribution of our blue individuals. In this section, we’re going to see if the distribution of the blue individuals differs from the Poisson distribution.

# Keep only blue individuals for this analysis, and rename the column to 
# something more descriptive
blue_lego <- community_data |>
  select(blue) |>
  rename(number_of_individuals = blue)

# Count the number of samples with each observed individual count
blue_lego_summary <- blue_lego |>
  group_by(number_of_individuals) |>
  summarise(observed = length(number_of_individuals))

# Quick visual check of the distribution
ggplot(data = blue_lego, aes(x = number_of_individuals)) +
  geom_bar()

Looking at our model data, we have no quadrats with zero individuals, two quadrats with 4 individuals, and four quadrats with 5 individuals.

Does this match what we would expect?

Next, we need to use this data to generated our expected number of quadrats that contain that number of individuals based on the poisson distribution. Based on the mean number of blue lego pieces per sample, how many samples do we expect to contain 4 or 5 individuals?

5.2.5 Poisson parameters

# For a Poisson distribution, mean ≈ variance; compare these to
# check fit
mean <- mean(blue_lego$number_of_individuals)
variance <- var(blue_lego$number_of_individuals)

total_blue <- sum(blue_lego$number_of_individuals)
total_samples <- length(blue_lego$number_of_individuals)

# Calculate the expected number of quadrats for each count under
# a Poisson distribution with lambda = sample mean
blue_lego_summary <- blue_lego_summary |>
  mutate(expected = dpois(number_of_individuals, lambda = mean) *
           total_samples)

We have now generated a new column in our dataset that shows the expected number of quadrats containing that number of individuals using the poisson distribution.

Unlike in our example plantago data (Chapter 4), we do not need to collapse any categories, as our predicted values are both greater than 1 in each category.

Lets calculate the Chi-squared value, and determine the P value:

# Compute each category's contribution to the chi-squared
# statistic
blue_lego_summary <- blue_lego_summary |>
  mutate(chi_sq = ((observed - expected)^2) / expected)

chi_sq_statistic <- sum(blue_lego_summary$chi_sq)

# Degrees of freedom = number of categories − 1 (for the test)
# − 1 (for the estimated parameter: the mean/lambda)
degrees_of_freedom <- nrow(blue_lego_summary) - 1 - 1

# P-value: probability of observing a chi-squared statistic this
# large or larger under the null hypothesis that counts follow a
# Poisson distribution
pchisq(chi_sq_statistic, df = degrees_of_freedom,
       lower.tail = FALSE)
[1] 0

What do you determine from this? Is the distribution of our blue samples significantly different to the poisson distribution?

Can you see how this code was modified from Chapter 4? Could you work out how to modify it for another ‘species’ of LEGO colour brick? Or how to modify it for your own data?

4.1 Plantago data

4.1.1 Introduction to the worked example

In the practical (Chapter 17), you investigated the distribution of populations of ribwort plantain (Plantago lanceolata) in a specific area of campus.

You used quadrats of two different sizes - 100cm x 100cm (large) and 40cm x 40cm (small) to determine the impacts that sampling efforts has on your findings.

You then entered your data onto the shared Google sheet.

In this worked example, we will consider the 2025 data from the Plantago datasheet.

First, you’ll need to run the relevant packages and read in the data from the practical. We’re using Google sheets to store the data; you can use the googlesheets4 package to read in from a google sheets document by extracting the unique code contained in the URL (see Figure 4.1). For this example, we’re going to work with the 2025 data, so the results for your data will look different.

4.1.3 Data preparation

Now we need to prepare the data. For this analysis, we’re going to use the large quadrats.

# Keep only large quadrats for this analysis
large_quad <- plantago_data |>
  filter(quadrat_size == "L")

# Count the number of quadrats with each observed individual count
large_quad_summary <- large_quad |>
  group_by(num_of_individuals) |>
  summarise(observed = length(num_of_individuals))

# Quick visual check of the distribution
ggplot(data = large_quad, aes(x = num_of_individuals)) +
  geom_bar()

What can we see about the distribution of our data? There are a large number of quadrats that contain 0 individuals or 1 individuals, followed by a long tail of quadrats that contain higher numbers of individuals.

Does this match what we would expect?

Next, we need to use this data to generated our expected number of quadrats that contain that number of individuals based on the poisson distribution. Based on the mean number of plants per quadrat, how many quadrats out of our total number of samples do we expect to contain 0, 1, 2, 3…, etc individuals.

4.1.4 Poisson parameters

# For a Poisson distribution, mean ≈ variance; compare these to
# check fit
mean <- mean(large_quad$num_of_individuals)
variance <- var(large_quad$num_of_individuals)

total_plants <- sum(large_quad$num_of_individuals)
total_quads <- length(large_quad$num_of_individuals)

# Calculate the expected number of quadrats for each count under
# a Poisson distribution with lambda = sample mean
large_quad_summary <- large_quad_summary |>
  mutate(expected = dpois(num_of_individuals, lambda = mean) *
           total_quads)

We have now generated a new column in our dataset that shows the expected number of quadrats containing that number of individuals using the poisson distribution.

However, the Chi-squared (\(\chi^2\)) test makes a few assumptions that we now need to check before we proceed with the statistical testing.

4.1.5 Chi-squared validity

The Chi-squared test requires expected values of ≥ 1 in each cell. When it comes to your data, you will need to now look at the generated table and determine where you see expected values of < 1; is it at the high end, the low end, or both ends of your data?

Where expected counts are too small, we collapse neighbouring categories. For example, if the expected value of the number of quadrats containing 11 individuals is below 1, we then collapse the data into “10 or more” individuals.

You may need to apply either or both of the following processes. For our 2025 data, you will need to do both.

4.1.5.1 Low end

The following code generates a value for the ‘low cutoff’ category. For the 2025 data, you can see that the expected number of quadrats with 0 individuals is 3.20 x \(10\^{-1}\), while the expected number of quadrats with 1 individual is 1.68.

# Inspect large_quad_summary to find where expected counts drop
# below 1 at the low end, then set low_cutoff to the last
# affected count. e.g. low_cutoff = 1 collapses counts 0 and 1
# into a single "≤ 1" category.
low_cutoff <- 1 # You might need to change this based on your data

large_quad_low <- large_quad_summary |>
  filter(num_of_individuals <= low_cutoff) |>
  summarise(num_of_individuals = low_cutoff,
            observed = sum(observed),
            expected = sum(expected))

4.1.5.2 High end

The following code generates a value for the ‘high cutoff’ category. For the 2025 data, you can see that the expected number of quadrats with 10 individuals is 1.54, while the expected number of quadrats with 11 individuals is 7.39 x \(10^{-1}\).

# Similarly, collapse the sparse high-count tail into a single
# "≥ high_cutoff" category. The expected value uses the Poisson
# survival function so it accounts for all counts from
# high_cutoff to infinity, not just those observed.
# e.g. high_cutoff = 10 collapses counts 10, 11, 12, … into one
# category.
high_cutoff <- 10 # You might need to change this based on your data

large_quad_high <- large_quad_summary |>
  filter(num_of_individuals >= high_cutoff) |>
  summarise(num_of_individuals = high_cutoff,
            observed = sum(observed),
            expected = (1 - ppois(10, lambda = mean)) * total_quads)

4.1.5.3 Bind the categories with the rest of the data

We then need to combine the collapsed categories with the untouched middle counts (>1 and <10). You will need to alter this code depending on which cutoff points you had to create; if you did not need to create a low cutoff point, you can exclude that command from your data.

# Bind the collapsed low and high categories with the untouched
# middle counts
large_quad_summary_comb <- large_quad_summary |>
  filter(num_of_individuals > low_cutoff,
         num_of_individuals < high_cutoff) |>
  bind_rows(large_quad_low, large_quad_high) |>
  arrange(num_of_individuals)

You can see from the table that the number of quadrats with the observed number of individuals pools the 0 and 1 categories, and the categories for 10 or more individuals.

4.1.6 The Chi-squared test

Remember the chi-squared equation? (Hint: check Chapter 1 if you don’t!)

\[ \chi^2 = \sum{(O - E)^2 \over E} \] We can now use this format to calcuate the chi squared statistic, and work out the P value that that represents

# Compute each category's contribution to the chi-squared
# statistic
large_quad_summary_comb <- large_quad_summary_comb |>
  mutate(chi_sq = ((observed - expected)^2) / expected)

chi_sq_statistic <- sum(large_quad_summary_comb$chi_sq)

# Degrees of freedom = number of categories − 1 (for the test)
# − 1 (for the estimated parameter: the mean/lambda)
degrees_of_freedom <- nrow(large_quad_summary_comb) - 1 - 1

# P-value: probability of observing a chi-squared statistic this
# large or larger under the null hypothesis that counts follow a
# Poisson distribution
pchisq(chi_sq_statistic, df = degrees_of_freedom,
       lower.tail = FALSE)
[1] 3.492703e-54

What can we conclude here? Is our data significantly different to the poisson distribution (i.e. randomly distributed)?

And by comparing the mean to the variance (hint: check Chapter 1 here as a reminder), do we think that the distribution of this plant is clustered or overdispersed?

4.1.7 Figure of observed and expected values

Finally, we can create a plot to visuliase our generated expected values using the poisson distribution, and our observed dataset

ggplot(large_quad_summary_comb, aes(x = num_of_individuals)) +
  geom_col(aes(y = observed)) +
  geom_point(aes(y = expected), 
             color = "red", size = 5, pch = 20) +
  # You might need to change breaks and labels based on your data
  scale_x_continuous(breaks = seq(1, 10, by = 1),
                     name = "Number of individuals per quadrat",
                     labels = c("0 or 1", 2:9, "10 or above")) +
  scale_y_continuous(name = "Number of quadrats\n(bars = observed, dots = expected)",
                     expand = c(0, 0)) +
  theme_classic()
